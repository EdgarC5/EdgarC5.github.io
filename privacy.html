Privacidad y datos de Google

Esta herramienta se utiliza de forma personal por el propietario del canal. El contacto de asistencia es el correo mostrado en la pantalla de consentimiento de Google del proyecto.

Datos utilizados y finalidad

Con consentimiento OAuth, se obtiene la identidad del canal seleccionado, sus estadísticas y los informes de YouTube Analytics que permita la cuenta. La lectura de ingresos estimados solo se solicita como permiso adicional. Estos datos sirven para comprobar el destino de las subidas, medir resultados y proponer mejoras del contenido. No se solicitan el correo de Gmail, contactos ni archivos de Google Drive.

Se envían a las APIs oficiales de YouTube los vídeos y metadatos autorizados. La programación y su retirada requieren permiso adicional. Las referencias públicas y las páginas oficiales se consultan como contexto y evidencia para los guiones.

Almacenamiento y acceso

La base de datos, proyectos, guiones, vídeos y registros se conservan en el ordenador del propietario. Los tokens OAuth y las sesiones de subida se cifran con DPAPI para su usuario Windows. El JSON del cliente OAuth permanece en el archivo local elegido; no se publica en esta página. El panel escucha en la dirección de bucle local del equipo.

Las observaciones públicas gestionadas por el programa tienen una caducidad de 30 días; el corpus automático de textos se renueva antes de reutilizar documentos con 24 horas de antigüedad. Los guiones, gráficos, narraciones y vídeos originales se conservan localmente hasta que el propietario los elimine; se distinguen de los datos obtenidos mediante las APIs de Google. Los informes privados disponibles se utilizan dentro de la instalación local.

Uso limitado y servicios externos

Los datos obtenidos de Google se utilizan para las funciones de creación, publicación y análisis descritas, de acuerdo con los requisitos de uso limitado de la Política de Datos del Usuario de los Servicios de API de Google. No se venden ni se usan para publicidad dirigida o para entrenar modelos generales. El motor generativo configurado por esta instalación funciona localmente.

Google recibe las solicitudes necesarias de autorización y las operaciones de YouTube. Los sitios consultados para investigación reciben las solicitudes de lectura habituales. Estas páginas informativas se alojan en GitHub Pages, en https://edgarc5.github.io/. GitHub puede registrar las visitas según sus propias condiciones; el contenido del canal y los tokens no forman parte de las páginas públicas.

Control y desconexión

El propietario puede detener las nuevas operaciones y solicitar la retirada de programaciones pendientes. La retirada debe comprobarse con YouTube: un vídeo ya publicado no se elimina automáticamente. Puede desconectar la cuenta y revocar el acceso desde su cuenta de Google; la herramienta intenta revocar y elimina sus credenciales locales, los informes autorizados y las referencias de API asociadas a las operaciones de publicación. Conserva únicamente recibos locales mínimos para impedir subidas duplicadas. Los vídeos originales del PC y los vídeos que ya existen en YouTube no se borran mediante esa desconexión.

Consulta la política de privacidad de Google. Puedes revisar y revocar el acceso desde tu cuenta de Google.
